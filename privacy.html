Datenschutz

Stand: 2026. Kontor ist eine lokal-first App: Deine Finanzdaten bleiben auf deinem Gerät.

Keine Server, keine Konten

Kontor verarbeitet keine personenbezogenen Daten auf einem Server. Es gibt keine Konten, keine Cookies, kein Tracking und keine Analyse-Dienste. Die Schriften sind selbst gehostet — es werden keine Google Fonts oder andere Drittanbieter aufgerufen.

Deine Daten bleiben auf dem Gerät

Alle Finanzdaten (Einkommen, Ausgaben, Depot-Journal, Einstellungen) speichert Kontor lokal im Browser (localStorage und IndexedDB) sowie in der Datei, die du selbst zum Verknüpfen oder Exportieren wählst. Diese Daten liegen im Klartext vor und werden nie hochgeladen. Bewahre daher eigene Backups per Export auf, und bedenke: Wer Zugriff auf dieses Gerät oder eine Exportdatei hat, kann die Daten lesen.

Auslieferung über GitHub Pages

Die App selbst wird über GitHub Pages ausgeliefert. Dabei sieht GitHubs Server — wie bei jedem Webseitenaufruf — übliche technische Server-Logs (z. B. IP-Adresse, User-Agent, angefragte Datei), um die App-Dateien zu übertragen. Deine Finanzdaten sind davon nie betroffen, da sie das Gerät nicht verlassen.

Deine Rechte (DSGVO)

Da serverseitig keine personenbezogenen Daten gespeichert werden, gibt es nichts, worauf zugegriffen oder was serverseitig gelöscht werden müsste. Du löschst deine Daten jederzeit selbst über Einstellungen → Alle Daten löschen.

English

No servers, no accounts

Kontor processes no personal data on any server. There are no accounts, no cookies, no tracking, and no analytics. Fonts are self-hosted — no Google Fonts or other third parties are ever contacted.

Your data stays on your device

All financial data (income, expenses, portfolio ledger, settings) is stored locally in your browser (localStorage and IndexedDB) and in the file you choose to link or export. This data is kept in plain text and is never uploaded. Keep your own backups with Export, and remember that anyone with access to this device or an exported file can read it.

Hosting via GitHub Pages

The app itself is served by GitHub Pages. As with any website request, GitHub's server sees standard technical logs (e.g. IP address, user agent, requested file) in order to deliver the app files. Your financial data is never part of that, because it never leaves your device.

Your rights (GDPR)

Because no personal data is stored server-side, there is nothing to access or erase on a server. You can delete your data at any time via Settings → Clear all data.
